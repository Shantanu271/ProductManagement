# Product Management 🛒

A modular Java-based backend application for managing product data. This project demonstrates clean architecture principles using controllers, services, models, and repositories—ideal for learning or building scalable enterprise applications.

## 📦 Project Structure

- `ProductController/` – Handles incoming requests and routes them to services
- `ProductService/` – Contains business logic for product operations
- `ProductModels/` – Defines product-related data structures
- `Repository/` – Interfaces for data access and persistence
- `ProductServiceApplication.java` – Main entry point for the application

## 🛠️ Tech Stack

- **Language:** Java
- **Framework:** Spring Boot (recommended for future integration)
- **Architecture:** MVC (Model-View-Controller)
